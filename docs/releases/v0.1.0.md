# Release Notes - v0.1.0 (Initial Open Source Release)

**Release Date**: October 2026  
**License**: MIT  
**Milestone**: Complete MVP (Tickets T01 through T21)

---

## Highlights

LLM Gateway v0.1.0 is the foundational open-source release providing a robust, high-performance, self-hosted proxy and cost/quality observability stack for engineering teams using foundation models.

---

## What's Included

### 1. Unified Gateway Proxy
- **OpenAI-Compatible Chat Completions**: Drop-in endpoint at `/v1/chat/completions` supporting both streaming (SSE) and non-streaming modes.
- **Provider Adapters**:
  - `openai`: GPT-4o, GPT-4o-mini, o1, o3-mini.
  - `anthropic`: Claude 3.5 Sonnet, Claude 3.5 Haiku, Claude 3 Opus (automatic format translation).
  - `gemini`: Gemini 1.5 Pro, Gemini 1.5 Flash via REST protocol.
  - `mistral`: Mistral Large, Mistral Small, Codestral.
  - `ollama` / `vllm`: Local inference support with custom `base_url`.
  - `mock`: Built-in zero-latency test provider for load testing and offline development.

### 2. Micro-USD Accounting & Pricing Catalog
- **Micro-USD Precision**: Cost tracked as exact integer micro-USD (`$1.00 = 1,000,000 µUSD`). Zero floating-point rounding drift.
- **Verifiable Seed Catalog**: Pre-populated model pricing with verified dates and official source documentation URLs.
- **Unpriced Safety**: Models with missing price records remain `cost = NULL` (never falsified as $0.00).

### 3. Reliability & Traffic Management
- **Automated Fallback Routing**: Instant failover upon upstream 429, 500, 502, 503, 504 errors or context limits with cycle detection.
- **Exact-Match Response Caching**: Sub-millisecond cache hits powered by Redis with streaming SSE chunk replay and `X-Gateway-Cache: bypass` support.
- **Sliding-Window Rate Limiting**: Per-project RPM enforcement with Lua-backed sliding window counters.
- **Budget Protection & Webhooks**: Daily and monthly project budgets with hard blocking (`429`) and automated threshold webhooks (50%, 80%, 100%).

### 4. Admin Dashboard (Next.js 16 + Tailwind v4)
- **Overview & KPIs**: Live total spend, request counts, average latency, and error rate with sparklines and comparison ranges.
- **Project Detail**: Usage graphs, key generator with one-time reveal dialog, visual fallback chain editor, and code snippet generator.
- **Request Explorer**: Full audit log with filtering by provider, status, date, model, and detailed request inspection drawer.
- **Models Comparison**: Comparative table of model volume, average latency, token costs, and user thumbs-up/down ratings.
- **Alerts & Settings**: Webhook history, provider credential vault (AES-256-GCM), custom price editor, and retention policies.

### 5. Security & Hardening
- **Zero-Secret Logging**: Automatic JSON log scrubber removes keys, tokens, and authorization headers.
- **AES-256-GCM**: Cryptographic encryption for provider credentials and webhook secrets with associated authentication data.
- **Argon2id**: High-security password hashing for admin credentials.
- **SSRF Hardening**: Outbound webhook validator blocks private networks, link-local, and cloud metadata IPs.
- **Benchmarked Overhead**: Measured p95 proxy overhead of **`41.71 ms`** (< 50 ms target).
